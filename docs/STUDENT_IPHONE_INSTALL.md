# Student iPhone Install Guide (Home Screen Web App)

Use this guide for the public student checker URL.

## 1) Before You Start
- Use Safari on iPhone.
- Use the student/public snapshot URL provided by your school.
- Internet connection is required to run checks.

## 2) Add To Home Screen
1. Open the student URL in Safari.
2. Tap the Share button.
3. Tap `Add to Home Screen`.
4. Keep the default app name (`Next Step`) or rename it.
5. Tap `Add`.

## 3) Use The App Icon
1. Tap the new Home Screen icon.
2. Enter courses and marks.
3. Tap `Check Eligibility`.
4. Review `Likely eligible`, `Likely ineligible`, and `Uncheckable`.
5. Check the dataset date banner on results.

## 4) Important Notes
- Results are advisory snapshot guidance, not final admission decisions.
- For non-High confidence rows, review the source program link before decisions.
- If your school also uses a staff app, students should not use the staff URL.

## 5) Troubleshooting
- Icon did not appear:
  - Ensure you used Safari (not Chrome/in-app browser), then retry `Add to Home Screen`.
- App opens old data:
  - Close and reopen, or open Safari URL and refresh once.
  - Verify the dataset date shown in the app.
- Check button fails:
  - Confirm internet is available and retry.
- Wrong URL:
  - Verify you are on the student/public snapshot URL, not the staff Apps Script URL.
